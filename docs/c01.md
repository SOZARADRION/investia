# C01 — primeira API local

Iniciada em 06/11/2026, após a conclusão da B03.

Escopo: projeto Python isolado em backend, FastAPI, GET /health tipado,
documentação interativa e testes de contrato HTTP. Sem dependências de
Firebase, credenciais administrativas ou dados de usuários. A rota é pública
e só informa status do processo. Acesso configurado em 127.0.0.1:8000.

O aplicativo Expo continua funcionando independentemente desta API.
Nenhum deploy, serviço pago ou alteração de regras do Firestore.

Próximo passo após validar a API: implementar e testar o cálculo determinístico
do simulador, definindo aporte no fim de cada mês, taxa mensal hipotética,
limites de entrada e arredondamento. Depois conectar a tela Android.

Instruções de instalação e execução: [backend/README.md](../backend/README.md).

Validação: três testes passaram com Python 3.13.5; pip check não encontrou
dependências quebradas. O TestClient emitiu aviso de descontinuação do
adaptador httpx na versão instalada de Starlette, sem falha dos testes.
Versões usadas registradas em backend/requirements-lock.txt.
